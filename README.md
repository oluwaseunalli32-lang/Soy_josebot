# Website SEO Checker Telegram Bot

A Telegram bot that inspects website URLs and returns metadata, performance, and basic SEO auditing details.

## Setup Instructions

1. Obtain a Bot Token from [@BotFather](https://t.me/BotFather) on Telegram.
2. Push this repository to GitHub.
3. Deploy as a **Background Worker** on Render.
4. Add environment variable `BOT_TOKEN` with your secret key.
